Web 3andak v3 — زر اختيار اللغة
================================

اللغات تظهر للمستخدم مباشرة على شاشة الدخول وفي الشريط العلوي بعد تسجيل الدخول. العربية هي الافتراضية، ويمكن تغييرها من زر 🌐 العربية. سيُحفظ اختيار المستخدم.

الملفات المهمة:
- index.html: يحتوي أزرار اللغة وروابط CSS وJavaScript.
- style.css: تنسيق الموقع وزر اللغة.
- language-picker.css: تنسيق نافذة اللغات.
- languages.js: فتح قائمة اللغات وتطبيق الاختيار.
- script.js: وظائف الموقع الحالية، أبقيناه كما هو.

افتح index.html مباشرة أو ارفع مجلد WEB 3ANDAK v3 كاملًا إلى الاستضافة. لا تنقل الملفات منفردة إلى مجلدات مختلفة. روابط الملفات موجودة داخل index.html.

بعد فتح الموقع، إذا لم يظهر التحديث، أعد تحميله بـ Ctrl+F5. زر اختيار اللغة ظاهر على شاشة الدخول، وكذلك في أعلى صفحات الموقع.

ملاحظة: بعض نصوص الصفحات والرسائل الطويلة قد تظل بالعربية حتى تُضاف ترجماتها إلى قاموس languages.js.
